# Finding1 Custom Import Instructions

This folder is a ready-to-run example for:

- `cyverApiCli pentester findings custom-import`

It is designed for environments where direct evidence creation via `/api/v2.2/.../evidences` may be blocked and the CLI must fall back to web-app service endpoints.

## Folder contents

- `findings_import.json` - finding manifest with nested `evidences`
- `SqlInjection.png` - local evidence file referenced by evidence data
- Optional snapshots generated by import:
  - `<finding-guid>.json`

## Manifest expectations

`findings_import.json` should include one finding object and an `evidences` array.

Each evidence item supports modal-style keys:

- `Title`, `Asset`, `Location`, `Version`, `Ip`, `Hostname`, `Port`, `Protocol`
- `IssueDetails`, `Reproduce`, `Evidence`, `IsVisibleInReport`
- `EvidenceFiles` (array)
- `NewEvidenceFiles` (array; can be empty in source file)

For file upload mapping, include file names under `EvidenceFiles` entries, for example:

- `FileName`: `SqlInjection.png`

The importer uploads local files first, captures `fileToken`, and injects tokens into upload payloads used during evidence creation fallback.

## Run command

From the `cyverApiCli` directory:

```bash
../cyverApiCli.exe -p sandbox pentester findings custom-import --project-id <PROJECT_UUID> ./import_templates/Finding1
```

Use `-vvv` for full debug HTTP traces:

```bash
../cyverApiCli.exe -vvv -p sandbox pentester findings custom-import --project-id <PROJECT_UUID> ./import_templates/Finding1
```

## Expected behavior

1. Finding is created (v2.2 API).
2. Evidence files are uploaded through `/App/Projects/UploadFindingEvidenceFiles`.
3. If `/api/v2.2/.../evidences` returns `403`, CLI falls back to `CreateOrEditFindingInstance`.
4. Snapshot file `<finding-guid>.json` is written in this folder.

## Notes

- A `403` on v2.2 evidence POST is expected in some tenants and is automatically handled by fallback.
- Some fallback responses return `success=true` with `result=null`; importer handles this as non-fatal when evidence creation appears successful.
